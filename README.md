# Miracles iOS — V1 (20/11)

تطبيق الآيفون حق متجر Miracles: غلاف (WKWebView) يفتح https://miracles.ly، زي تطبيق أندرويد.
المتجر نفسه ما يتغيرش، وأي تعديل في الموقع يوصل للتطبيق من غير بناء جديد.

## خطوات معتز (مرة وحدة)

1. **مستودع جديد:** في GitHub اضغط **+** ← **New repository**
   - الاسم: `Miracles-iOS`
   - **Public** (عام: البناء مجاني ومن غير حد)
   - ما تختارش README ولا .gitignore ولا license.
   - اضغط **Create repository**.
2. **رفع الملفات:** في صفحة المستودع الفاضي اضغط **uploading an existing file**.
   - فك `Miracles iOS V1.zip` على اللابتوب.
   - افتح المجلد، وحدد **كل اللي فيه** (`Miracles` و `project.yml` و `README.md` و `.github`).
   - اسحبهم كلهم مع بعض لصفحة الرفع ← **Commit changes**.
3. **تأكّد إن ملف البناء اترفع:** في المستودع لازم يطلع مجلد `.github`.
   **لو ما طلعش** (ويندوز أحياناً ما يرفعش المجلدات اللي تبدا بنقطة):
   1. اضغط **Add file** ← **Create new file**.
   2. اكتب في خانة الاسم بالضبط: `.github/workflows/ios.yml`
   3. افتح الملف `ios.yml` من المجلد اللي فكّيته (`.github` ← `workflows`) بالـ Notepad.
   4. حدد الكل وانسخه، والصقه في GitHub.
   5. اضغط **Commit changes**.
4. **البناء:** يبدا لحاله بعد الرفع. تتابعه من تبويب **Actions** ← **iOS build**، وياخذ حوالي 10–15 دقيقة.
   - **✓ أخضر:** افتح البناء وانزل لتحت لـ **Artifacts** ← حمّل `miracles-ios-N`. فيه:
     - صور الفتحة الأولى (1، 2، 4، 8، 15 ثانية).
     - فيديو الفتح `open.mp4`.
     - صورة الفتحة الثانية.
     - `build.log`.
   - **✗ أحمر:** اضغط على الخطوة الحمرا، صوّر الأخطاء (الجزء اللي بين «BUILD FAILED» والخط) وابعتها، أو حمّل الـ Artifacts وابعت `build.log`.
5. لو حبيت تعاود البناء بدون رفع: **Actions** ← **iOS build** ← **Run workflow**.

## شن فيه

| | |
|---|---|
| المعرّف (Bundle ID) | `ly.miracles.app` (نفس أندرويد، ما يتغيرش بعد أول رفع) |
| الاسم تحت الأيقونة | Miracles |
| الأيقونة | 1024×1024 من الشعار الأصلي (748px، تصغير مش تكبير) بنفس تركيب أيقونة أندرويد، بدون شفافية |
| شاشة البداية | نفس تسخينة المتجر: الشعار 190×178 في نص الشاشة + 7، خلفية `#FBF9F7` (فاتحة دايماً، زي أندرويد) |
| الأجهزة | آيفون بس، طولي، iOS 16 وفوق |
| الموقع يعرف إنه تطبيق | هوية المتصفح فيها `MiraclesiOS/1.0.0` ← الموقع V105 يعطيه حاجات التطبيق (بدون تكبير ولا نسخ الأسعار، تسخينة 2.5 ث، الشعار الليلي)، **بدون** الإشعارات خارج التطبيق (لين APNs) |
| الدفع (إيزون) | داخل التطبيق ويرجع للمتجر لحاله. لو صفحة البنك فتحت نافذة جديدة: تطلع فوق المتجر بزر «إغلاق» |
| روابط برا | واتساب، فيسبوك، تيك توك، إنستغرام، الإيميل، الاتصال، الخرائط ← تطبيقاتها (أو Safari) |
| الرجوع | بالسحب من حافة الشاشة |
| بدون نت | شاشة «لا يوجد اتصال بالإنترنت» + «إعادة المحاولة»، وترجع للمتجر لحالها أول ما النت يرجع |
| مشاركة المنتج / الإيصال | قائمة المشاركة متاع الآيفون (حفظ الصورة، واتساب...) |
| الوضع الليلي في المتجر | شريط الحالة والخلفية يتبعوا لون المتجر |
| الدخول | منفصل عن Safari: الزبونة تدخل مرة وحدة في التطبيق (الجلسة الوحدة لكل حساب زي ما هي) |

## الجاي (بعد ما يتفعّل حساب Apple Developer)

1. شهادة التوقيع + Provisioning Profile + مفتاح App Store Connect API في GitHub Secrets (مرة وحدة).
2. خطوة ثانية في `ios.yml` تبني نسخة موقّعة وترفعها لـ TestFlight لحالها ← تجربة على الآيفون 16.
3. صفحة التطبيق في App Store Connect (الوصف، الصور، الخصوصية) ← المراجعة.
4. لاحقاً: الإشعارات خارج التطبيق (APNs).
